# ☕ Java Studies Repository

## 📌 About

This repository is dedicated to learning **Java from the basics**, progressing step by step into **Object-Oriented Programming (OOP)** concepts.

The goal is to build a solid foundation through continuous practice, exercises, and small projects. This is an **ongoing learning journey**, so new content will be added regularly.

---

## 🎯 Objectives

* Learn Java fundamentals from scratch
* Understand core programming logic
* Master Object-Oriented Programming (OOP) concepts:

  * Encapsulation
  * Inheritance
  * Polymorphism
  * Abstraction
* Apply knowledge through practical exercises and projects
